# FemmeFinancial
A personal project building a mobile budget tracking app that also has an AI assistant built in. The goal is to help younger people like myself who had no one to teach them finances figure it out and track it all in one place!  

# Agent
- run "python agent.py" in terminal 
- ENTER or "exit" to leave the agent 

- based on the 50/30/20 rule of finance
- used the 3 times monthly needs to calculate emergency fund. 

- qwen3.4:4b model for now.
